# 环形链表回顾 (Linked List Cycle Review)

LeetCode 141 | 归档: 2026-06-24 | 状态: 已回忆（本轮未继续推导）

## 本轮回忆

看到题目后，用户立即认出这是之前做过的环形链表问题，并回忆起快慢指针方法：

- 慢指针每次走 `1` 步
- 快指针每次走 `2` 步
- 无环时，快指针最终到达 `null`
- 有环时，两个指针最终会在环内同一节点重合

## 手动模拟

### 无环

链表：`1 -> 2 -> 3 -> 4 -> null`

```text
初始：slow = 1, fast = 1
第 1 轮：slow = 2, fast = 3
第 2 轮：slow = 3, fast = null
结论：不存在环
```

### 有环

链表从节点 `4` 指回节点 `2`。

```text
初始：slow = 1, fast = 1
第 1 轮：slow = 2, fast = 3
第 2 轮：slow = 3, fast = 2
第 3 轮：slow = 4, fast = 4
结论：同一时刻指针重合，存在环
```

## 本轮校正

用户原本表述为：快指针到达慢指针曾经走过的位置后，就会追上慢指针。

更精确的判定是：历史上访问过同一节点并不足以判环，必须在同一轮满足 `slow == fast`。
