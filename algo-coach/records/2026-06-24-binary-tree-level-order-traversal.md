# 二叉树的层序遍历 (Binary Tree Level Order Traversal)

LeetCode 102 | 归档: 2026-06-24 | 状态: 逻辑闭合（待判题）

## 核心洞察（一句话）

递归遍历时携带节点所在层数，将节点值追加到二维结果数组对应的层，就能按层组织输出。

## 当前方案

用户最初同时提到队列和递归层数，后续明确采用递归方案：

- 使用外置二维数组保存每层结果
- 递归函数接收当前节点和 `layer`
- 当前节点为空时结束
- 当前层不存在时创建该层数组
- 将当前节点值追加到对应层
- 先递归左子树，再递归右子树
- 左右孩子都使用 `layer + 1`

先左后右的深度优先访问虽然会先深入左侧，但层数决定节点写入哪一个子数组；同一层的节点仍会按照左子树到右子树的访问顺序追加，因此保持从左到右。

## 追问阶段卡点与突破

1. **队列与递归层数两种方案混在一起**：队列可以按层做广度优先遍历，递归也可以通过携带层数完成分组。本轮最终使用递归层数方案，不需要同时维护队列
2. **确认层数参数不会被左子树污染**：`layer` 是递归调用的局部参数。左子树返回后，上层的层数不变，因此左右孩子会收到相同的下一层编号
3. **Python 列表操作写错**：最初使用 `array[layer][-1] = tree.val`，这会覆盖该层最后一个元素，不是向尾部追加
4. **一度考虑每层使用链表**：题目最终要求二维数组，链表还需要额外转换；当前需求可以直接使用 Python 列表尾部追加
5. **新层条件最初判断为“大于”**：初始 `array = []`、根节点 `layer = 0` 时，`layer > len(array)` 不成立，因此无法初始化根节点所在层
6. **尝试改为从 `layer = -1` 开始**：如果先判断再自增，判断发生时根节点仍处于 `-1` 层，不能正确创建第 `0` 层
7. **最终确定层级不变量**：根节点从第 `0` 层开始；当 `layer == len(array)` 时创建新层；随后追加当前节点；左右孩子接收 `layer + 1`

## 最终逻辑

```text
遍历(node, layer):
    node 为空时结束
    layer 等于当前结果层数时，创建新层
    将 node.val 追加到该层
    遍历左孩子，层数为 layer + 1
    遍历右孩子，层数为 layer + 1
```
