#### 1. 199. 二叉树的右视图

给一棵二叉树，假设你站在树的右侧，只记录每一层最右边能看到的节点。

例如：

```text
    1
   / \
  2   3
   \   \
    5   4
```

从右边看，能看到：

```text
[1, 3, 4]
```

注意，答案不是简单沿着 `right` 指针一直走。

例如：

```text
  1
 /
2
 \
  5
```

右视图是：

```text
[1, 2, 5]
```

核心难点：如何准确找到每一层最后一个节点，或者确保每一层最先访问到的是最右节点。

#### 2. 102. 二叉树的层序遍历

按层访问二叉树，从上到下，每一层从左到右输出。

例如：

```text
    3
   / \
  9  20
     / \
    15  7
```

输出：

```text
[
  [3],
  [9, 20],
  [15, 7]
]
```

它和普通递归遍历不同。

前序、中序、后序更关注一条分支不断深入；层序遍历要求：

1. 先处理完当前层；
2. 再处理下一层。

核心难点：如何知道当前层有多少个节点，从而把不同层正确分组。

#### 3. 105. 从前序与中序遍历序列构造二叉树

给定同一棵树的前序遍历和中序遍历，要求还原原树。

例如：

```text
前序：[3, 9, 20, 15, 7]
中序：[9, 3, 15, 20, 7]
```

对应的树是：

```text
    3
   / \
  9  20
     / \
    15  7
```

已知：

- 前序：根 → 左 → 右
- 中序：左 → 根 → 右

因此前序的第一个元素一定是当前树根节点。

在中序序列中找到根节点后：

- 根节点左边：左子树
- 根节点右边：右子树

核心难点：如何根据左子树长度，继续切分前序和中序序列，并让递归子问题保持一致。

#### 4. 114. 二叉树展开为链表

把二叉树原地展开成一条只使用右指针的链表。

展开顺序必须等于原树的前序遍历顺序。

例如：

```text
    1
   / \
  2   5
 / \   \
3   4   6
```

展开后：

```text
1 → 2 → 3 → 4 → 5 → 6
```

要求：

- 每个节点的 `left = null`
- 每个节点通过 `right` 指向下一个节点

核心难点：展开左子树后，原本的右子树应该接到哪里，同时还不能把右子树入口弄丢。

这题不仅是遍历，还涉及修改树的指针结构。

#### 5. 236. 二叉树的最近公共祖先

给定二叉树中的两个节点 `p` 和 `q`，找出同时包含它们的最低祖先节点。

例如：

```text
      3
     / \
    5   1
   / \ / \
  6  2 0  8
    / \
   7   4
```

如果：

```text
p = 5
q = 1
```

最近公共祖先是：

```text
3
```

如果：

```text
p = 5
q = 4
```

最近公共祖先是：

```text
5
```

因为节点也可以是自己的祖先。

核心难点：递归返回时，如何区分“这一侧找到了 `p`”“这一侧找到了 `q`”以及“两边分别找到了一个”。

这五道题分别训练：

- 199：层与视角
- 102：逐层遍历
- 105：遍历序列与分治重建
- 114：遍历顺序与指针重组
- 236：递归返回信息的设计
