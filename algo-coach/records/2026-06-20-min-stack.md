# 最小栈 (Min Stack)

LeetCode 155 | 归档: 2026-06-20 | 状态: 已推导（待判题）

## 核心洞察（一句话）

主栈保存真实元素，辅助栈与主栈同步，并在每个位置保存“截至当前位置的最小值”，因此入栈、出栈和获取最小值都能保持 `O(1)`。

## 追问阶段卡点与突破

1. **先想到维护一条最小值链表**：新元素更小时，将它连接到当前最小值之前；相同时保留重复节点，以便弹出一个最小值后仍能得到正确结果
2. **较大元素是否需要写入辅助结构**：最初认为压入比当前最小值大的元素时，不需要新增最小值节点
3. **通过 `3, 2, 5` 暴露同步问题**：如果压入 `5` 时辅助结构不移动，弹出 `5` 时就无法与主栈无条件同步
4. **转为完全同步结构**：压入较大元素时也复制一份当前最小值，使两个结构始终等长；出栈时两边同步弹出，不需要额外判断

## 用户原始推演

```text
入栈 3
链表 null，记录 3

入栈 2
2 -> 3
2 和当前链表位置 3 比较；2 更小，将 2 连入链路

入栈 2
2 -> 2 -> 3
2 和当前链表位置 2 比较；相同，直接保留 2

出栈 2
链表当前位置从 2 移动到下一个 2，剩余 2 -> 3
```

对于 `3, 2, 5`，用户进一步明确：

> `5, 2, 3` 的时候最小值链是 `2 -> 2 -> 3`，因为大的元素是直接复制前一个链表节点的最小值。

## 完整结构

- 主栈保存真实元素
- 辅助栈与主栈同步，每个位置保存截至该位置的最小值
- 入栈时，辅助栈压入 `min(当前元素, 之前最小值)`
- 出栈时，两个结构同步弹出
- `getMin()` 直接读取辅助栈顶部
- 时间复杂度：入栈、出栈、取最小值均为 `O(1)`
- 额外空间复杂度：`O(n)`
